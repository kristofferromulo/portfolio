# Kristoffer Lopez — portfolio

Static site: open `index.html` in a browser, or upload this whole folder to any static host (Netlify, Vercel, GitHub Pages, Wix Studio custom code, etc.).

- `index.html` holds all markup, styles and scripts.
- `img/` holds the images (WebP).
- Fonts load from Google Fonts (Geist, Geist Mono). Offline, the page falls back to Helvetica/Arial.
- Case studies are views on the same page: `index.html#thesis` and `index.html#olynation`.
